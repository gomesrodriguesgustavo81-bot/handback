# Handback

**Você recebe, a gente devolve conferido.**

O Handback recebe entregas (de equipes, colaboradores ou clientes), confere com IA
o que foi pedido e devolve uma avaliação aprovada por uma pessoa.

## Pastas

| Pasta | O que tem |
|---|---|
| `prototipo/` | O app original em Google Apps Script, que já funciona num curso com 6 equipes. Serve de modelo. |

O código do sistema novo entra a partir da Fase 0 (Fundação).
